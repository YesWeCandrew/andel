# Andel

Andel has been a mini project to build an app that genuinely helps organise my life admin:
- Chores
- Meal plans
- Recipes
- Shopping lists

It is fully built to meet my needs after finding other alternatives too complex or difficult.

I don't expect to build on this much more, unless I find new and interesting things I'd like to do with it, but have made it public on the off chance anybody else wants to do something similar and a starting point might be useful.
